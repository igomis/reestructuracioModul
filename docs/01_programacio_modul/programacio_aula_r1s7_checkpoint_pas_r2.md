# R1S7. Checkpoint de pas a R2

## Finalitat de la sessió

Esta sessió tanca el tram inicial del curs i verifica que el projecte pot entrar en `R2` sense arrossegar una base opaca o no executable.

## Encaix dins del Repte 1

- **Repte**: `R1. Kickoff backend`
- **Microrepte**: `Sessió sense microrepte propi`
- **Sessió**: `R1S7`
- **Duració orientativa**: `3 hores`
- **Focus**: tancament de base, evidències, README, defensa curta i preparació de formularis de `R2`
- **No entra encara**: implementar el flux complet de `R2`

## Seqüència d'aula de 3 hores

### 0:00-0:30. Inventari d'evidències

Revisar entorn, punt d'entrada, README, commits i AI log.

### 0:30-1:20. Correcció guiada

Tancar incidències que impedixen reproduir el projecte.

### 1:20-2:10. Mini defensa de base

Cada alumne explica domini, decisió tècnica, arrencada i primer punt d'entrada.

### 2:10-2:40. Preparació de `R2`

Identificar el primer flux de dades que es treballarà amb formularis i validació.

### 2:40-3:00. Acta de pas

Classificar: acreditat, correcció curta o recuperació.

## Evidències mínimes

| Evidència | Mínim acceptable |
|---|---|
| Base executable | arranca i respon |
| README | permet reproduir l'estat |
| Traçabilitat | commits i incidències visibles |
| Pas a R2 | primer flux de dades identificat |
