# R1S6. Primer flux backend guiat

## Finalitat de la sessió

Esta sessió amplia el treball del primer punt d'entrada amb una pràctica guiada de lectura de petició, resposta del servidor i verificació manual. No crea un nou microrepte: reforça el pas de tenir entorn a tenir backend observable.

## Encaix dins del Repte 1

- **Repte**: `R1. Kickoff backend`
- **Microrepte**: `Sessió sense microrepte propi`
- **Sessió**: `R1S6`
- **Duració orientativa**: `3 hores`
- **Focus**: petició, resposta, punt d'entrada, evidència i lectura d'errors
- **No entra encara**: formularis, sessions, login o BBDD

## Seqüència d'aula de 3 hores

### 0:00-0:30. Recordatori client-servidor aplicat

Relacionar navegador, servidor, ruta i resposta real.

### 0:30-1:10. Modelatge de punt d'entrada

Crear o revisar una resposta mínima amb valor de diagnòstic.

### 1:10-2:00. Treball guiat

L'alumnat ajusta el punt d'entrada al seu producte.

### 2:00-2:35. Prova i captura d'evidència

Registrar URL, resposta esperada i error si apareix.

### 2:35-3:00. Checkpoint

Validar que el backend respon i que l'alumnat sap explicar el recorregut.

## Evidències mínimes

| Evidència | Mínim acceptable |
|---|---|
| Punt d'entrada | resposta real del backend |
| Prova | URL o comanda reproduïble |
| Explicació | petició -> servidor -> resposta |
| README | estat actualitzat |

## Checklist de tancament

- [ ] Punt d'entrada funcional.
- [ ] Prova reproduïble.
- [ ] README actualitzat.
- [ ] Recorregut explicable.
