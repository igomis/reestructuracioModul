# R1S3. Domini, ADR i decisió tècnica inicial

## Finalitat de la sessió

Esta sessió consolida el domini del projecte i una primera decisió tècnica abans d'entrar en construcció sostinguda. No crea un microrepte nou: dona temps real d'aula a decidir, justificar i deixar rastre.

## Encaix dins del Repte 1

- **Repte**: `R1. Kickoff backend`
- **Microrepte**: `Sessió sense microrepte propi`
- **Sessió**: `R1S3`
- **Duració orientativa**: `3 hores`
- **Focus**: domini, abast inicial, ADR curt, riscos i criteri de producte
- **No entra encara**: formularis, autenticació o persistència funcional

## Seqüència d'aula de 3 hores

### 0:00-0:30. Revisió de dominis possibles

Contrastar dominis massa grans, massa genèrics o poc verificables.

### 0:30-1:10. Modelatge d'un ADR curt

Mostrar com justificar una decisió tècnica amb context, opcions, decisió i conseqüències.

### 1:10-2:00. Redacció guiada

L'alumnat escriu el primer ADR o nota tècnica equivalent.

### 2:00-2:35. Contrast per parelles

Una altra persona intenta entendre el domini, l'abast i la decisió sense explicació oral.

### 2:35-3:00. Checkpoint docent

Validació del domini i ajust d'abast si cal.

## Evidències mínimes

| Evidència | Mínim acceptable |
|---|---|
| Domini | acotat i viable |
| ADR | decisió inicial justificada |
| Riscos | almenys dos riscos o límits |
| Traçabilitat | commit o issue identificable |
