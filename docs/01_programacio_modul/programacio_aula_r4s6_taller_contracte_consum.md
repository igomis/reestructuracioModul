# R4S6. Taller de coherència contracte-consum

## Finalitat de la sessió

Esta sessió reforça `R4` entre la construcció de l'API i la microdefensa. La funció és comprovar que contracte, implementació, consum i errors conten la mateixa història.

## Encaix dins del Repte 4

- **Repte**: `R4. API i serveis reutilitzables`
- **Microrepte**: `Sessió sense microrepte propi`
- **Sessió**: `R4S6`
- **Duració orientativa**: `3 hores`
- **Focus**: coherència contracte-resposta, col·lecció de proves, client de consum i errors
- **No entra encara**: integració híbrida de `R5`

## Seqüència d'aula de 3 hores

### 0:00-0:30. Auditoria ràpida de contracte

Comparar documentació amb resposta real.

### 0:30-1:20. Consum guiat

Executar peticions principals amb eina, script o client.

### 1:20-2:00. Errors i cas denegat

Comprovar error de validació, recurs no trobat o accés denegat si aplica.

### 2:00-2:35. Ajust de documentació

Corregir diferències entre contracte i codi.

### 2:35-3:00. Preparació de defensa R4

Triar endpoint crític i prova que es defensarà.

## Evidències mínimes

| Evidència | Mínim acceptable |
|---|---|
| Contracte | coincideix amb resposta real |
| Consum | prova reproduïble |
| Error | cas incorrecte documentat |
| Defensa | endpoint crític identificat |

## Checklist de tancament

- [ ] Contracte revisat.
- [ ] Consum reproduïble.
- [ ] Error comprovat.
- [ ] Endpoint de defensa triat.
