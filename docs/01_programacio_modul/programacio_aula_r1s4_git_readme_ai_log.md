# R1S4. Git, README i AI log operatiu

## Finalitat de la sessió

Esta sessió assegura que el treball del curs serà rastrejable. El centre no és aprendre Git des de zero, sinó usar-lo com a evidència professional del procés.

## Encaix dins del Repte 1

- **Repte**: `R1. Kickoff backend`
- **Microrepte**: `Sessió sense microrepte propi`
- **Sessió**: `R1S4`
- **Duració orientativa**: `3 hores`
- **Focus**: commits útils, README executable, AI log i registre d'incidències
- **No entra encara**: avançar funcionalitats sense traçabilitat mínima

## Seqüència d'aula de 3 hores

### 0:00-0:30. Què és una evidència de procés

Comparar un repositori opac amb un repositori defensable.

### 0:30-1:10. Modelatge de README executable

Mostrar seccions mínimes: objectiu, arrencada, decisions, estat i incidències.

### 1:10-1:50. Commits i missatges útils

Revisar exemples de commits massa grans, massa buits o interpretables.

### 1:50-2:30. AI log i registre d'ajuda

Preparar el fitxer i registrar un primer exemple real o simulat.

### 2:30-3:00. Revisió creuada

Una altra persona comprova si podria arrancar o entendre el projecte amb el README.

## Evidències mínimes

| Evidència | Mínim acceptable |
|---|---|
| README | instruccions inicials i estat real |
| Commits | almenys un commit funcional i explicable |
| AI log | plantilla i criteri d'ús |
| Incidències | primer registre o apartat preparat |

## Checklist de tancament

- [ ] README executable.
- [ ] Commits amb sentit.
- [ ] AI log preparat.
- [ ] Incidències o decisions registrables.
