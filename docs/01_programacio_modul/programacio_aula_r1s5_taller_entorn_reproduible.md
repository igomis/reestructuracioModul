# R1S5. Taller d'entorn reproduïble

## Finalitat de la sessió

Esta sessió dona marge d'aula per estabilitzar l'entorn abans que el primer punt d'entrada del backend es convertisca en evidència. No substituïx `R1M2`; el prepara i evita que el repte quede bloquejat per ports, versions o arrencades no reproduïbles.

## Encaix dins del Repte 1

- **Repte**: `R1. Kickoff backend`
- **Microrepte**: `Sessió sense microrepte propi`
- **Sessió**: `R1S5`
- **Duració orientativa**: `3 hores`
- **Focus**: arrencada, dependències, ports, serveis i comprovació reproduïble
- **No entra encara**: desenvolupar lògica de producte complexa

## Seqüència d'aula de 3 hores

### 0:00-0:25. Diagnòstic d'entorns

Identificar versions, serveis, ports i errors habituals.

### 0:25-1:10. Modelatge d'arrencada neta

Executar una arrencada des de zero i documentar passos.

### 1:10-2:10. Taller guiat

L'alumnat estabilitza el seu entorn i registra incidències.

### 2:10-2:40. Prova creuada

Una altra persona intenta seguir les instruccions d'arrencada.

### 2:40-3:00. Checkpoint tècnic

Classificar: entorn validat, incidència menor o bloqueig que necessita intervenció.

## Evidències mínimes

| Evidència | Mínim acceptable |
|---|---|
| Arrencada | servidor o contenidor funcional |
| README | passos actualitzats |
| Incidència | errors i solució registrats |
| Verificació | prova d'una altra persona o del professorat |

## Checklist de tancament

- [ ] Entorn arranca.
- [ ] Ports i versions documentats.
- [ ] Incidències registrades.
- [ ] Preparat per a punt d'entrada funcional.
