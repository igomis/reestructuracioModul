# MT15. Defensa tècnica curta

Micro-presentació docent breu per a `R5S5`. Equival aproximadament a `6` diapositives.

## Diapositiva 1. Idea central

- defensar no és llegir el README
- defensar és explicar decisions i evidències
- el codi ha de poder modificar-se i provar-se

## Diapositiva 2. Guió de 5 minuts

- problema del domini
- flux principal
- decisió tècnica important
- prova o evidència
- error controlat
- limitació o millora pendent

## Diapositiva 3. Preguntes probables

- on està esta regla?
- què passa si falla esta entrada?
- per què ho has posat en esta capa?
- com ho provaries?
- què ha fet la IA i què has verificat tu?

## Diapositiva 4. Canvi en directe

- localitzar el codi
- explicar què es tocarà
- fer un canvi menut
- executar prova o demo curta
- deixar constància del resultat

## Diapositiva 5. Evidència del dia

- guió curt de defensa
- una pregunta crítica preparada
- una prova reproduïble
- una limitació reconeguda
- AI log revisat si aplica

## Diapositiva 6. Tancament

- una defensa sòlida no amaga errors, els contextualitza
- l'autoria es veu quan pots explicar i ajustar
- pregunta final: quina part del teu projecte pots defensar sense mirar apunts?
