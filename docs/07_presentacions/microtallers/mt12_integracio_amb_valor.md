# MT12. Triar una integració amb valor

Micro-presentació docent breu per a `R5S1`. Equival aproximadament a `6` diapositives.

## Diapositiva 1. Idea central

- integrar no és enganxar un servei extern qualsevol
- la integració ha d'aportar valor al producte
- ha de poder provar-se i defensar-se

## Diapositiva 2. Valor possible

- automatitzar una tasca
- notificar un canvi important
- enriquir dades del domini
- sincronitzar informació
- verificar un estat extern
- generar una evidència útil

## Diapositiva 3. Frontera entre sistemes

- què és responsabilitat del backend propi?
- què aporta el sistema extern?
- quines dades ixen?
- quines dades entren?
- què passa si falla?

## Diapositiva 4. Errors habituals

- integrar per moda
- dependre d'un servei no reproduïble
- no tractar errors
- exposar secrets
- no connectar la integració amb cap flux real

## Diapositiva 5. Evidència del dia

- mapa d'integració
- justificació de valor
- contracte o endpoint extern
- dada que entra o ix
- primer risc identificat

## Diapositiva 6. Tancament

- una integració bona fa més útil el producte
- una integració ornamental només afegeix soroll
- pregunta final: què pot fer ara el producte gràcies a esta integració?
