# MT06. Debugging i prova curta

Micro-presentació docent breu per a `R2S7`. Equival aproximadament a `6` diapositives.

## Diapositiva 1. Idea central

- "funciona" no és una prova
- una prova curta ha de ser repetible
- depurar és reduir incertesa

## Diapositiva 2. Abans de tocar codi

- quin comportament esperaves?
- què ha passat realment?
- amb quines dades?
- en quin punt del flux?
- pots repetir-ho?

## Diapositiva 3. Prova mínima

- pas inicial
- acció executada
- resultat esperat
- resultat real
- evidència de verificació
- decisió posterior

## Diapositiva 4. Depuració ordenada

- comprovar entrada
- comprovar validació
- comprovar estat o sessió
- comprovar persistència si existeix
- comprovar resposta

## Diapositiva 5. Evidència del dia

- una prova curta documentada
- un error reproduït o descartat
- una correcció menuda
- una limitació anotada
- commit de tancament

## Diapositiva 6. Tancament

- una prova imperfecta però repetible val més que una demo oral
- el checkpoint demana evidència, no confiança
- pregunta final: quina prova repetiries davant del professorat?
