# MT02. README executable i commit defensable

Micro-presentació docent breu per a `R1S2`. Equival aproximadament a `6` diapositives.

## Diapositiva 1. Idea central

- el repositori ha de parlar abans de la defensa
- un README executable evita dependència oral
- un commit defensable explica una decisió o avanç real

## Diapositiva 2. README mínim

- requisits
- instal·lació
- arrencada
- URL o punt d'entrada
- prova ràpida
- estat actual i limitacions

## Diapositiva 3. Commit defensable

- té un objectiu clar
- no barreja moltes coses inconnexes
- deixa el projecte en estat raonable
- es pot explicar en una frase
- connecta amb una tasca o decisió

## Diapositiva 4. Errors habituals

- README copiat i no provat
- instruccions que només funcionen en una màquina
- commits gegants al final
- missatges com `final`, `coses`, `update`
- no registrar problemes coneguts

## Diapositiva 5. Evidència del dia

- README amb arrencada real
- primer punt funcional verificat
- commit amb missatge concret
- nota de limitacions
- captura o comanda de comprovació si ajuda

## Diapositiva 6. Tancament

- una altra persona hauria de poder arrancar el projecte
- el teu historial ha de mostrar procés, no només resultat final
- pregunta final: quin commit explica millor què has aconseguit hui?
